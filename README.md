# EastKeeps

公开的中国元素商品HTML图册，包含120款商品、10条Pinterest灵感、内嵌图片、来源外链与筛选功能。

访问：https://zzzhan-lab.github.io/eastkeeps/

仅发布静态HTML及站点必要文件。完整商品目录、结构化数据、SKU表和本地运行记录不在本仓库中。

数据快照：2026-11-02。部分为历史样本或Etsy公开索引快照；价格非实时成交价，Pinterest收藏不是销量。

图片及商品资料权利归来源方；保留原始链接用于研究参考。本仓库不对第三方素材授予再利用许可。

平台分别展示：Amazon 18款（海外零售参考）、1688 12款（国内供给参考）、独立站78款、Etsy12款、Pinterest10条。默认打开Amazon栏目，各平台的搜索和形态筛选彼此独立。
